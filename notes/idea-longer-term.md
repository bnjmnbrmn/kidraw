# Longer-term ambitions

Open-ended directions worth keeping in mind even though they're not next.

- **AI generation / refactoring of diagrams.** Prompt → diagram, or "rearrange this diagram for clarity."
- **Auto-arrangement of nodes and subsets.** Beyond what the physics routers do — layout aware of semantic groups.
- **OpenClaw integration** (the wider context this project sits in).
- **Slack / WhatsApp / API integrations.** Drop a kidraw diagram into a chat; receive one as the result of a workflow.
- **Private deployments** for organisations.
- **Sequence / class / UML diagram support.** Specialised diagram types with their own constraints — extend the model beyond plain directed graphs.
