# Keyboard-first philosophy and ergonomic goals

The thesis kidraw is built on:

- **Keyboard-first.** Primary interaction via keyboard; mouse is secondary or non-existent.
- **Home-row centric.** High-frequency actions live on the home row or within easy reach without moving the hand.
- **Command-execution model.** Select → Act → Reset. Selection is ephemeral and clears after the action.
- **Ergonomics.**
  - Stronger fingers (index, middle) for frequent / critical actions.
  - Weaker fingers (pinky) for less frequent or modifier-like states.
  - "Opposite-hand" principle for submenus, to balance load.
- **Flexibility.** The codebase supports rapid iteration of key layouts so we can test ergonomic theories empirically. See [architecture-key-profiles](architecture-key-profiles.md).
