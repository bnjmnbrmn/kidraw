# Graph management UI

The serialization work shipped Open / Save As / Export Zip / Cycle Display. What's missing is a *graph manager* surface:

- List of saved graphs (by name).
- Rename / delete from the list.
- Switch between them without opening the file picker each time.
- Search.

Longer term: cloud storage as a paid option, with sync across devices. AWS / SSO / roles ([idea-infrastructure-deploy](idea-infrastructure-deploy.md)).
