# Real-world test cases

UX acceptance criteria — diagrams real users would actually build, used to drive design and routing decisions.

- **Vim commit-history diagram.** Tests graph navigation, labelling, branching topology.
- **Org chart.** Tests tree layout, node sizing, hierarchy.

These are not automated; they're benchmarks the dev runs by hand to see whether the tool *feels* right.
