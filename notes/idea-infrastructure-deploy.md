# Infrastructure

Production-readiness items:

- **Analytics** (GA4 or alternative).
- **AWS deployment** — secure setup, SSO, role-based access.
- **CI/CD pipeline** for automated testing on push / PR.
- **Reusable libraries** — extract the keymenu and other reusable bits into separate packages ([idea-keymenu-as-library](idea-keymenu-as-library.md)).

None of this is on the critical path until kidraw is shareable / multi-user. Right now it lives entirely on the developer's machine and as a localStorage draft.
