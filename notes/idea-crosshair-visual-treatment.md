# Crosshair visual treatment

The crosshairs should feel like an interaction cursor, not like a diagram
element. Explore visual treatments that separate it from graph content:

- distinct cursor-only color that does not overlap normal node/edge palettes,
- subtle animation or pulse while idle/moving,
- transparency or screen-space styling that reads as UI chrome,
- alternative shapes for movement modes without making the cursor feel like a
  diagram object,
- making adaptive hit-radius changes less visually distracting.

This is separate from movement semantics: first decide how the cursor should
look and feel, then tune how much of that visual shape should correspond to the
actual hit area.
