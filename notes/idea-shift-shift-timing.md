# Shift-shift timing

Double-Shift returns to `normal` mode from anywhere. The interval within which the two Shift presses count as a "double" feels too aggressive currently — accidentally triggers when the user really meant two separate Shift presses.

Slow it down — try ~3 seconds, at least for now. The interval is currently a magic number; revisit as part of [idea-drawing-area-refactor](idea-drawing-area-refactor.md)'s constants centralisation.
