# Proximity selection feedback

When the crosshairs are near a waypoint / node / label but not over it, give a hint that the item is targetable. Today there's only the crosshairs selection circle ([architecture-invariants](architecture-invariants.md) #11) — the user has to know that anything inside the circle is selectable.

Possible feedback:

- Highlight the nearest targetable item as crosshairs approach.
- Subtle pulse / outline when the item enters the circle.
- Show distance / direction hint in the header during navigation.
