# Multi-select

- **Drag-box selection.** Crosshairs marquee select — pull a rectangle across the canvas; nodes / edges / waypoints inside join the selection.
- **Extend select.** A modifier (e.g. holding Shift while `c`'ing) adds the targeted item to the selection rather than replacing. Earlier work removed a "select-falls-through" prototype in anticipation of this; do it properly.
- **Should multi-select persist across Select+Drag holds?** Probably not initially — kept single-select for now.
