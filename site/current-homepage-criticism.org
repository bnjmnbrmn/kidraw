#+title: Current Homepage Criticism

In general, this feels too much like a sales brochure and not enough like an academic document.  I want it to be drier, and much more concise.

Let's start by making "KiDraw" much bigger, and treat "A keyboard-first graph editor" as a subtitle (so slightly smaller).  "Connect your thoughts, at the speed you have them" should be smaller still.

Instead of using the term graph in this page, let's just use the term "diagram".

I think we can mostly get rid of the text that isn't actually in the screenshot.  For example, in this section "The First Box, It starts with one box", we see the text "KiDraw" in three places, not including the header in the screenshot.  I just want to see the screenshot, zoomed in a bit more on the KiDraw box, with the box centered between the top of the key menu and the bottom of the header (rather than in the center of the screenshot).  In addition, we really don't need all this filler text, like "It starts with one box"--sounds like an ad for athletic-wear.  The text "The first box. Everything else on this page hangs off it, and the whole graph gets built inside KiDraw as you scroll." is also unnecessary.  You can keep "Everything below is one graph, built inside KiDraw as you scroll. These are frames from the running app, not drawings of it.", except maybe change it to something like "The following description of KiDraw uses actual screenshots of KiDraw".

In general for these screenshots, rather than having these boxes all the same size, I think we should have the boxes fit the text they contain (I think this is the default setting in KiDraw).  Also, when we are focusing on a particular node, like "KiDraw" in the first screenshot, I want to be 1) centered on it and 2) have it selected (with the blue highlighting).  Also, let's make the default zoom level for these screenshots higher in general.

"It works, and it is not finished. Whether a keyboard-first diagram editor is actually nicer to use is the open question."  Change this to "It works, but it isn't finished and has some rough edges.  I'd love to hear your ideas about how to improve it."
