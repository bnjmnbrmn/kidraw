KiDraw puts a crosshair on the canvas and an on-screen keyboard under it. Every key you can press is shown, and what it does changes with the mode you are in. Nodes, edges, labels, layouts — all of it from the home row.

The idea

Three things, and you know the whole app

h j k l

A crosshair, not a pointer

You move a cursor around the canvas with the same keys vim uses. Nodes are created where it sits, links start from what it is over, and navigation jumps it between real graph items rather than pixels.

hold a key

The menu is the documentation

The keyboard on screen shows every binding available right now. Hold a key with a cut corner and its submenu slides in on top. Nothing to memorise, and nothing hidden behind a toolbar.

esc

Modes, like an editor

Typing a label is a mode; adding a node is a mode; navigating is a mode. The cards change with it, and a chip at the bottom of the screen always says which one you are in.

Where it is

Honest status

KiDraw is an alpha built by one person. It is good at what it was built for — thinking in graphs quickly — and it has rough edges everywhere else. Worth knowing before you open it:

Storage
Local files and folders. Nothing is uploaded anywhere.
Browser
Chromium-based browsers get the full file support.
Collaboration
None yet. One person, one graph.
Mouse
Works, but the keyboard is the design.
Mobile
Not yet — it wants a keyboard.
Stability
Under daily change. Expect bugs; they get fixed fast.

Try it

The alpha is live, free, and needs nothing installed. Press a when it loads, type a name, and you have made your first node.
